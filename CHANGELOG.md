# История версий «Помощника валидации проверок»

Новые версии — сверху. Номер текущей версии лежит в файле `VERSION`; он должен
совпадать с верхней записью. Новую запись удобнее всего добавлять батником
`release\bump_version.bat`: он сам поднимет номер и поставит дату.

Формат заголовка: `## <версия> — <ГГГГ-ММ-ДД>`, ниже — пункты списком.

## 1.0.001 — 2026-10-27
- Первая версия: чек-лист задач из похожих проверок по выгрузке JSON (гипотезы и задачи)
- Похожесть по «сути» проверки, объяснение похожести, отметка «есть в программе», типовые задачи
- Выгрузка чек-листа в Excel и Word, светлая и тёмная тема
- Запуск через start.bat (как в Toolbox ARM), пересчёт базы — precompute.bat
- Автообновление из Bitbucket: проверка по номеру версии, установка и перезапуск из интерфейса
